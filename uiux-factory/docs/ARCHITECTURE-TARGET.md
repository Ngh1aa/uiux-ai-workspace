# Target architecture: cloud-first Design Engineering Harness

The intended collaboration model is ChatGPT/remote AI reasoning + GitHub source of truth + GitHub Actions execution. The repository should keep design intelligence, skills, contracts, orchestration, verification and evidence generation, while local-only UI/server/provider surfaces become optional or are removed when no longer referenced.

Target flow:

`AI collaborator -> GitHub branch/PR -> Actions runner -> render/browser/a11y/performance/visual evidence -> AI review/repair -> merge`

The repository should not require a powerful local LLM or local Workbench to use its core value.
