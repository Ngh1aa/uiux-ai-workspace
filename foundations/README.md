# Nền tảng kiến thức

Kiến thức nền giải thích **vì sao** một màn đẹp và dùng được, để các luật trong
[`TASTE.md`](../TASTE.md), [`CRAFT.md`](../CRAFT.md) và các skill không chỉ là danh sách phải thuộc.
Chỉ mở trang cần cho việc đang làm; khối kế hoạch thị giác trong `CRAFT.md` nên trỏ được về đây.

| Trang | Đọc khi |
|---|---|
| [`layout-and-density.md`](layout-and-density.md) | Chia vùng, lưới 12 cột, mật độ, khoảng trống thừa, màn desktop và canvas |
| [`gestalt-and-hierarchy.md`](gestalt-and-hierarchy.md) | Nhóm khối, thứ bậc thị giác, tự kiểm bằng nheo mắt và bản xám |
| [`composition.md`](composition.md) | Cân bằng, nhịp, khối lượng thị giác; landing mỗi section một hình |
| [`typography-vietnamese.md`](typography-vietnamese.md) | Chọn font có dấu tốt, khoảng dòng, ngắt dòng, số và tiền tệ tiếng Việt |
| [`color-oklch.md`](color-oklch.md) | Màu theo vai trò, dựng thang OKLCH bằng `oklch-scale.py`, tương phản, chế độ tối |
| [`motion.md`](motion.md) | Khi nào có chuyển động, thời lượng, đường cong, giảm chuyển động |
| [`illustration-and-imagery.md`](illustration-and-imagery.md) | Ảnh hay minh hoạ, hệ minh hoạ đồng bộ, ảnh giữ chỗ, icon |
| [`reference-gallery.md`](reference-gallery.md) | Chọn tham khảo cho từng loại màn: nhìn ai, học gì, ghép pattern nào |

Thuật ngữ dùng trong các trang này được chốt trong [`GLOSSARY.md`](../GLOSSARY.md).
