# Example — Route a school redesign project

Request: “Redesign website trường hiện tại, giữ sitemap/content tốt, nhiều hình ít chữ, prototype tương tác như thật.”

Routing:
1. Profile: `education` + `website-audit-and-redesign`.
2. Audit current site before IA changes.
3. Education playbook defines parent/admissions journey.
4. Brand + visual + media direction define image-heavy language.
5. IA/content compress information without deleting trust/SEO value.
6. Design system + interaction skill define reusable states.
7. Prototype implementation uses realistic navigation/forms/search states; backend persistence may be mocked if out of scope.
8. Responsive/a11y/visual QA + release evidence.

Not routed by default: SaaS, hospitality, ecommerce, government playbooks.
