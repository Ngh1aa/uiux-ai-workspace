# Project Gate

## Strategy
- [ ] Problem/audience/JTBD/scope known.
- [ ] Primary domain/profile selected.
- [ ] Existing-site preservation audit done when relevant.

## UX/UI
- [ ] Primary journeys mapped.
- [ ] IA/page roles coherent.
- [ ] Brand/visual direction implementable.
- [ ] P0 components/states defined.
- [ ] Content/CTA/proof hierarchy defined.

## Build
- [ ] Reuse/architecture decisions reasonable.
- [ ] Responsive/a11y constraints implemented.
- [ ] Critical interactions and states work.

## Release
- [ ] Build/type/lint/test checked.
- [ ] Visual QA representative viewports.
- [ ] A11y/SEO/performance/security triaged.
- [ ] Analytics if in scope.
- [ ] Known issues and unverified claims documented.
