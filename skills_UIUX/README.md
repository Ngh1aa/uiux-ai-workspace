# skills_UIUX

Thư viện skill UI/UX dùng khi Claude thiết kế website và app qua chat.

**Không bắt đầu từ file này.** Bắt đầu từ [`START-HERE.md`](../START-HERE.md) và chọn skill theo cỡ
việc trong [`WORKFLOWS.md`](../WORKFLOWS.md). Chỉ đọc những skill được chỉ định.

| Có gì | Ở đâu |
|---|---|
| Các skill, mỗi skill một thư mục có `SKILL.md` | xem [`SKILL-CATALOG.md`](SKILL-CATALOG.md) |
| Script soát trang đã dựng | [`ui-craft-and-visual-qa/scripts/`](ui-craft-and-visual-qa/scripts/README.md) |
| Template tài liệu UX (khung vấn đề, luồng, wireframe, visual brief) | [`templates/ux/`](templates/ux/README.md) |
| Kiểm tra cấu trúc `SKILL.md` | `python3 skills_UIUX/scripts/validate-skills.py` |

Bộ chạy tự động cũ (flows, profiles, packs, prompts, evals, vendor, designlib) đã được gỡ khỏi
`main`; bản đầy đủ ở nhánh `archive/truoc-khi-gon-lan-2`.
