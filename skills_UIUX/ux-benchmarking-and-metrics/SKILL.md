# UX Benchmarking & Metrics

## Workflow
1. Select representative critical tasks and user segments.
2. Define task success before testing.
3. Choose metrics that answer a decision: success, completion quality, time, errors/recovery, ease/satisfaction and relevant behavior analytics.
4. Capture baseline under documented conditions.
5. Test comparable tasks after design changes.
6. Pair numbers with qualitative causes.
7. Report trend, uncertainty and limitations.

## Rules
- Do not optimize vanity metrics at the expense of task success.
- Keep task definitions stable across benchmark rounds.
- Segment by device/context only when it materially affects interpretation.
- Treat small samples cautiously; do not fake statistical certainty.

## Quality gate
Metrics answer a real product question and use the same success definition before and after the change.
