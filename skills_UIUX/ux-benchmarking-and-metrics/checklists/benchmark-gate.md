# Benchmark Gate

Each item is pass or fail. Any fail blocks publishing the benchmark as a comparison.

- [ ] The decision the benchmark informs is written at the top of the report.
- [ ] Study type is declared as formative or summative, and numbers are reported accordingly.
- [ ] Every task has a frozen wording, start state and success criterion written before the first session.
- [ ] Partial success, assistance and timeout rules are defined and applied consistently.
- [ ] Baseline and follow-up rounds share protocol, environment class and recruit criteria, or deviations are logged and the comparison is downgraded.
- [ ] Every completion rate shows n and a 95% adjusted Wald interval.
- [ ] Task time states whether it covers successes only, and uses geometric mean for small samples.
- [ ] Questionnaires are named standard instruments (SEQ, SUS, UMUX-Lite) scored by their published method.
- [ ] Each primary metric has at least one guardrail with a threshold set before data collection.
- [ ] Each task row carries at least one qualitative cause for failures.
- [ ] Limitations section lists what the data cannot support.
- [ ] No claim of significance without a test suited to the design.
