# Research Foundations — Real-World Artifact & Domain Metaphor Design

Checked: 2026-08-31

This skill is informed by current/public UX guidance. These sources support the **principles**, not a universal instruction to make interfaces look physical.

## Apple Human Interface Guidelines — Design principles / Familiarity

Source: https://developer.apple.com/design/human-interface-guidelines/design-principles

Key adaptation:
- build on physical and digital concepts people already know;
- familiar patterns help people predict behavior;
- consistency reinforces learnability;
- delight should not become decoration that blocks the task.

## Apple WWDC26 — Principles of great design

Source: https://developer.apple.com/videos/play/wwdc2026/250/

Key adaptation:
- metaphor can make software immediately understandable;
- a metaphor can fail when too literal or too abstract;
- familiar common actions should retain expected meaning.

## Nielsen Norman Group — Match Between the System and the Real World

Source: https://www.nngroup.com/articles/match-system-real-world/

Key adaptation:
- users carry mental models from real-world experience into digital systems;
- familiar objects/activities can reduce learning burden;
- resemblance that does not map to expected function can confuse users;
- matching the real world goes beyond visual imitation into natural mappings and language.

## Nielsen Norman Group — Skeuomorphism

Source: https://www.nngroup.com/articles/skeuomorphism/

Key adaptation:
- distinguish skeuomorphism as a functional learning aid from decorative visual trend;
- physical resemblance is useful when it helps people understand an unfamiliar interface;
- unnecessary textures/shadows/realism are not the goal.

## Object-Oriented UX (OOUX)

Sources:
- https://ooux.com/
- https://ooux.com/resources/object-oriented-ux

Key adaptation:
- structure complex systems around the real-world objects in users' mental models;
- define object identity/relationships/attributes/actions before jumping to procedural flows;
- artifact research can inform IA and content models even when no visual skeuomorphism appears.

## Repository interpretation

The `skills_UIUX` skill therefore uses physical/domain references as one evidence source among project truth, user research, brand, production references and technical reality.

It deliberately rejects the rule:

> physical artifact exists → website should imitate it.

Instead:

> verified mental model + relevant task + transferable property → choose the lowest useful metaphor fidelity → adapt to brand/digital conventions → verify.
