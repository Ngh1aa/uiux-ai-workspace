# Experience Principles & Signature Moments

## Principle
Brand guidelines describe identity; experience principles describe how the service should feel in use.

## Create 3–5 experience principles
Each principle must:
- reflect user need + brand/service truth;
- guide a real design tradeoff;
- be specific enough to reject alternatives;
- apply across multiple pages;
- avoid generic adjectives like "modern" or "premium" alone.

Examples of useful form:
- `Explore before explain` — lead experiential offerings with credible visual exploration before long exposition.
- `Evidence before claims` — pair important claims with proof near the decision point.
- `Confident, never noisy` — use strong hierarchy and restraint rather than simultaneous promotional emphasis.

## Define signature moments
Select a few moments worth making memorable, such as:
- first arrival/hero;
- category/campus/building explorer;
- comparison/selection moment;
- storytelling transition;
- form completion/confirmation;
- handoff into a human/physical experience.

A signature moment must advance the journey. Do not create spectacle detached from a task.

## Principle-to-system mapping
For each principle map implications for:
- content;
- layout;
- imagery;
- interaction;
- motion;
- proof;
- CTA;
- accessibility/reduced-motion fallback.

## Required artifact
`docs/experience-principles.md`.

## Gate
During critique, major page decisions should be explainable using user evidence, project constraints and one or more experience principles.

## Anti-patterns
- Ten+ vague principles nobody can remember.
- Principles that simply restate visual style words.
- Signature animation that slows critical tasks.
- Copying memorable interactions from references without brand/service rationale.
