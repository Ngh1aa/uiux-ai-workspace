# Skill Review Gate

## Discovery
- [ ] Folder name == frontmatter name.
- [ ] Description says what + when in third person.
- [ ] Trigger vocabulary specific enough.

## Scope
- [ ] Capability boundary differs from existing skills.
- [ ] Dependencies/composition described when relevant.

## Context
- [ ] SKILL.md concise and workflow-first.
- [ ] Long references/examples moved out.
- [ ] Resource links direct and descriptive.
- [ ] No duplicated long rules across files.

## Execution
- [ ] Workflow has actionable steps.
- [ ] Output format/gate clear.
- [ ] Failure/anti-patterns included where valuable.

## Verification
- [ ] Structural validators pass.
- [ ] Representative evals exist/run for important behavior.
- [ ] Catalog/profile updated if routing changes.
