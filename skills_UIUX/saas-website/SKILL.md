# SaaS Website Playbook

## Core journey

`Problem recognition → value understanding → capability fit → proof/risk reduction → pricing/commitment → signup/demo`

## Messaging

Hero phải nói outcome + audience/context, không chỉ slogan trừu tượng. Feature copy giải thích user job/result, không list technical noun.

## Core pages

- Product/features.
- Use cases/solutions.
- Pricing.
- Integrations if relevant.
- Security/trust.
- Customers/case studies.
- Resources/docs.
- Signup/demo/contact.

## Product proof

Use real UI/screenshots/demos selectively. Screenshot phải có context/annotation nếu complexity cao; không tạo decorative dashboard fake chỉ để nhìn tech.

## Pricing

Clarify plan difference, billing unit, limits và next action. Comparison table focus decision criteria, không hàng trăm checkmarks vô nghĩa.

## Conversion

Distinguish self-serve (`Start trial`) và sales-assisted (`Book demo`) nếu cả hai tồn tại. Không để chúng cạnh tranh mọi viewport.

## Acceptance criteria

- [ ] Value proposition cụ thể.
- [ ] Product proof có context.
- [ ] Pricing/plan differences understandable.
- [ ] Signup/demo flow match business model.
- [ ] UI không rơi vào generic card soup nếu brand không yêu cầu.
