# Human-AI Interaction Design

## Workflow
1. Define user need and why AI is appropriate.
2. Explain capability and limits at the moment they matter.
3. Design input guidance/examples without overclaiming.
4. Decide when confidence, rationale or source context is useful.
5. Provide feedback, correction, regenerate/undo and human override where appropriate.
6. Design uncertainty, refusal and failure as normal states.
7. Clarify data use and whether user feedback changes the system.

## Quality gate
AI identity/capability is not misleading; users retain meaningful control; failures provide a path forward; confidence is not false precision; high-impact use has appropriate human review.

## Baseline
Google PAIR People + AI Guidebook: mental models, explainability/trust, feedback/control and graceful failure.
