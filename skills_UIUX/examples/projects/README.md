# Project profile examples

Mỗi folder minh họa file `.uiux-profile.json` đặt tại repository root của project thật.

- `qtsc/`: corporate prototype + redesign specialist + explicit source-of-truth.
- `luxroom/`: ecommerce prototype.
- `redesignvas/`: education prototype + redesign specialist.
- `capital/`: real-estate/building prototype + redesign specialist.
- `studioos/`: SaaS/application prototype.

Copy file phù hợp về project root rồi chỉnh `project`, `source_of_truth`, `constraints` theo repository thực tế.
