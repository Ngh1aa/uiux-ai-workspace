# Brand Recognition Validation

## Principle
The V4 cropped-screenshot check is a useful internal heuristic. It becomes evidence only when the validation method and participants are defined.

## Workflow
### 1. Define the question
Examples:
- Can target users associate cropped digital screens with the correct brand?
- Which cues drive recognition without the logo?
- Are users confusing the site with competitors/category defaults?

### 2. Build representative stimuli
Sample multiple templates/viewports and meaningful states. Use agreed conditions such as:
- full screen;
- cropped section;
- logo/name hidden;
- competitor/category controls.

Do not deliberately remove cues that users would normally encounter unless that condition answers a specific research question.

### 3. Recruit the relevant audience
Record familiarity with the brand/category. Existing customers and prospects may produce different results.

### 4. Measure
Depending on scope, capture:
- correct association;
- misattribution/confusion;
- cue recall/recognition;
- qualitative explanation;
- response time only when the test setup supports meaningful timing.

### 5. Interpret conservatively
Report sample, protocol and uncertainty. Do not manufacture statistical significance or universal brand-recall claims from a convenience sample.

## Required artifact
Create/update `docs/brand-recognition-validation.md` with stimuli, participants, protocol, results, limitations and design implications.

## Gate
Use words like "validated recognition" only when real participant evidence exists. Otherwise label the result `internal recognition heuristic`.

## Anti-patterns
- Designer self-rating reported as user validation.
- Testing only the homepage hero.
- Comparing against obviously unrelated competitors.
- Treating primary color recall as complete brand recognition.
- Reporting precise significance without a valid analysis plan.
