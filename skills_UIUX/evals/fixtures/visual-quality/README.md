# Visual Quality Fixtures & Briefs

Thư mục này chứa 10 sample briefs và content outlines đại diện cho 10 loại website, dùng cho benchmark đánh giá chất lượng visual (Phase 3 - Visual Quality Eval):

1. **Corporate**: `corporate-brief.json` (Tư vấn chiến lược / Kiến trúc B2B)
2. **Education**: `education-brief.json` (Học viện quốc tế / Tuyển sinh & Trải nghiệm học đường)
3. **E-commerce**: `ecommerce-brief.json` (Thương hiệu thủ công thủ pháp / D2C storefront)
4. **Portfolio**: `portfolio-brief.json` (Studio thiết kế sáng tạo / Senior Product Designer)
5. **SaaS**: `saas-brief.json` (Nền tảng Cloud Developer Tooling / API platform)
6. **Hospitality**: `hospitality-brief.json` (Khu nghỉ dưỡng sinh thái / Boutique Eco-Resort & Dining)
7. **News**: `news-brief.json` (Tạp chí điện tử độc lập / Long-form editorial & investigative journalism)
8. **Non-Profit**: `nonprofit-brief.json` (Tổ chức bảo tồn biển & khí hậu / Quỹ hành động)
9. **Real Estate**: `real-estate-brief.json` (Dự án căn hộ sinh thái hạng sang / Showroom bất động sản)
10. **Startup**: `startup-brief.json` (AI Robotics / Frontier Tech seed-stage launch)

Ngoài ra thư mục còn chứa `sample-site/` gồm các trang mẫu HTML hợp lệ dùng để chạy thử nghiệm deterministic gates của `scripts/visual-quality-grader.py`.
