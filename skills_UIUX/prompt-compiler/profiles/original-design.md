# Profile — Original Design

Use when there is no authoritative existing implementation that must be reconstructed or preserved.

## Source hierarchy

1. explicit user brief;
2. project context / brand truth;
3. current research and domain evidence;
4. applicable UIUX Factory skills/rubrics;
5. deliberate proposals;
6. assumptions only when needed to continue.

## Compile

- audience/problem/JTBD and project scope;
- critical journey and page roles;
- research/reference principles without copying proprietary layouts;
- 3 art-direction adjectives and signature concept;
- palette/type/grid/media/motion system;
- IA/routes/states/components;
- responsive strategy;
- accessibility/performance/SEO/deployment only when applicable;
- exact deliverables and QA.

Concrete new values such as colors, type scale, spacing, breakpoints, and motion timing should be labelled `PROPOSED` when intentionally chosen by the system.

Use `ASSUMED` for missing contextual facts, not for deliberate design decisions.

The Adaptive Prototype Quality Rubric may guide prototype visual quality, but heuristic defaults are not universal hard laws.
