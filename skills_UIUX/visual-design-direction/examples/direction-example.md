# Example — Institutional technology campus

Visual attributes: **credible, infrastructural, connected, contemporary, human**.

Translate thành rules:
- Layout: strong horizontal grid, large factual data bands, fewer rounded cards.
- Type: confident sans display + highly readable body; data labels compact.
- Color: brand primary cho action/wayfinding, white canvas dominant, tint dùng cho grouping.
- Imagery: real campus/infrastructure/people-at-work; avoid abstract AI network stock art.
- Graphic device: thin route/network lines dùng tiết chế để liên kết ecosystem sections.
- Motion: subtle directional reveals/number transitions; no floating blobs.

Điểm chính: adjective phải map thành implementable visual decisions.
