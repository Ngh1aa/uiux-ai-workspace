# Visual Direction Gate

- [ ] Visual attributes có concrete rules, không chỉ adjectives.
- [ ] Grid/container/content widths defined.
- [ ] Section rhythm không monotone.
- [ ] Type hierarchy + mobile scale defined.
- [ ] Color roles defined.
- [ ] Image/icon/illustration direction defined.
- [ ] Radius/border/elevation consistent với brand.
- [ ] Motion purpose/intensity + reduced motion defined.
- [ ] Tested trên ít nhất 2 page types.
- [ ] No obvious generic AI template smell.
