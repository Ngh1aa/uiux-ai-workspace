# Visual Craft Reference

## Layout grammar questions

- Nội dung chủ yếu editorial, transactional, catalogue hay storytelling?
- Page cần dense comparison hay cinematic persuasion?
- Khi nào full-bleed? Khi nào narrow reading width?
- Section transition dựa vào whitespace, rule, background, imagery hay type scale?

## Hierarchy

Mỗi viewport nên có dominant focal point. Hạn chế nhiều heading/button cùng contrast/size tranh attention.

## Typography

Evaluate bằng content thật:
- Vietnamese diacritics;
- long organization/program names;
- numbers/data;
- button labels;
- 2–4 dòng paragraph mobile.

Line length body long-form thường cần giới hạn hợp lý; không kéo paragraph full 1440px.

## Color

Define roles:
- canvas/surface;
- primary action;
- accent/highlight;
- text primary/secondary;
- border/divider;
- status;
- inverse/on-brand.

## Image art direction

Specify subject, composition, light, crop, authenticity, diversity/context, prohibited clichés. Hero image cần desktop/mobile crop plan nếu framing khác nhau.

## Motion

Intensity tiers:
- functional: hover/focus/open/close;
- orienting: section/page transition;
- expressive: hero/reveal moments.
Expressive motion là minority, không blanket every element.
