# Dashboard Gate

Mark each item PASS or FAIL with evidence (screenshot, spec row or test note).

- [ ] Every panel has a written question and an owner or action.
- [ ] Panel order matches the actionability ranking in the spec.
- [ ] Every KPI delta names its comparison basis and period.
- [ ] Units, timeframe and timezone are visible on every panel.
- [ ] Bar and area value axes start at zero, or the exception is documented.
- [ ] No meaning is carried by color alone; checked with a color vision deficiency simulation.
- [ ] Pie or donut charts, if any, have three parts or fewer.
- [ ] Last-updated time is visible; stale state triggers when the freshness SLA is exceeded.
- [ ] Loading, empty, no-data, partial, error and permission states are defined per panel.
- [ ] One failing panel does not blank the dashboard.
- [ ] Important charts have a text summary and a data table alternative.
- [ ] Tooltip-only values are also reachable by keyboard and touch.
- [ ] Tested with extremes: zero, null, outlier, long labels, one dominant category.
