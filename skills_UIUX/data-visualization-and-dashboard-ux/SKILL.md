# Data Visualization & Dashboard UX

## Workflow
1. Define audience, decision and monitoring cadence.
2. Establish KPI hierarchy before chart type.
3. Match visualization to comparison, trend, distribution or relationship task.
4. Use overview → filter/zoom → details when exploration is needed.
5. Show units, timeframe, freshness and source/context.
6. Provide accessible text/table alternatives for important data.
7. Design loading, no-data, stale-data and error states.

## Quality gate
Every visualization answers a named question; color is not the sole encoding; units/timeframes are explicit; dashboard order follows actionability.
