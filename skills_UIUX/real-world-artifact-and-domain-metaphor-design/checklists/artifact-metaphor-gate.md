# Artifact / Domain Metaphor Gate

Use before handing a concept to visual design or implementation.

## Source truth
- [ ] Artifact exists in the domain or is clearly labeled `CONCEPT/UNKNOWN`.
- [ ] Real branded product uses official/current asset/spec when applicable.
- [ ] No fake official mark, certification, network, financial instrument or sensitive data.

## Mental model
- [ ] Target audience is likely to recognize the artifact/ritual.
- [ ] The expected meaning/action matches the digital use.
- [ ] The metaphor does not require special explanation to understand a core task.

## Transfer discipline
- [ ] Design problem is stated first.
- [ ] Transfer layer: form / structural / information / behavioral / ritual.
- [ ] Fidelity L0–L4 selected intentionally.
- [ ] “Keep” and “do not copy” properties documented.
- [ ] Lowest useful fidelity chosen.

## System quality
- [ ] Fits brand rather than creating a separate theme.
- [ ] Does not create a collage of unrelated metaphors.
- [ ] Works with real content/data lengths.
- [ ] Mobile can recompose rather than shrink a physical replica.
- [ ] Semantics and accessibility work without visual recognition.
- [ ] Performance cost is proportionate.

## UX integrity
- [ ] Standard controls keep standard meaning.
- [ ] Core CTA/navigation remains obvious.
- [ ] Physical-world friction is not copied when digital can remove it.
- [ ] No UX-improvement claim without validation/evidence.
