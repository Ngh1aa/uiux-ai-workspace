# Hospitality Website Playbook

## Core journey

`Inspiration → property fit → rooms/offers/experience → location & trust → availability/booking → confirmation`

## Content hierarchy

- Distinctive property promise.
- Rooms/accommodation or service catalogue.
- Amenities/experiences/dining.
- Gallery with useful captions/context.
- Location/access.
- Offers/packages.
- Policies/FAQ.
- Booking/contact.

## Media

Use real property media with consistent art direction. Hero video must never make text unreadable or delay access to booking.

## Booking UX

- Date/guest/room inputs obvious.
- Price inclusions and fees transparent.
- Availability failure has alternatives.
- External booking engine transition should feel intentional and trustworthy.

## Mobile

Sticky/visible booking action can help, but must not cover content or accessibility controls.

## Acceptance criteria

- [ ] Experience and practical booking info balance.
- [ ] Media is purposeful and performant.
- [ ] Booking transition is clear.
- [ ] Fees/policies are not hidden.
- [ ] Mobile booking controls are usable.
