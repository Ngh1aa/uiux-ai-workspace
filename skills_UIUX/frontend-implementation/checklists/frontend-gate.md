# Frontend Implementation Gate

## Architecture
- [ ] Reused existing components/tokens where appropriate.
- [ ] No obvious duplicate UI implementation.
- [ ] New dependency justified.

## UI/UX
- [ ] Real content/state used.
- [ ] Loading/empty/error/success states theo scope.
- [ ] Primary CTA/task works.
- [ ] Representative mobile/tablet/desktop inspected.

## Accessibility
- [ ] Semantic controls.
- [ ] Keyboard/focus critical interactions checked.
- [ ] Labels/names/errors correct.

## Quality
- [ ] Build passes.
- [ ] Type/lint/tests run when configured.
- [ ] No console errors on primary flow.
- [ ] Images/scripts/font usage reviewed for obvious performance regression.
- [ ] Known limitations documented.
