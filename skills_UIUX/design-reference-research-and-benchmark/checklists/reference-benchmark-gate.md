# Reference Benchmark Gate

Use before handing research to `visual-design-direction`.

## Context

- [ ] Business goal is explicit.
- [ ] Audience/top task is explicit or marked as assumption.
- [ ] Domain/page type is known.
- [ ] Brand constraints are known.
- [ ] Existing strengths to preserve are recorded for redesigns.

## Source quality

- [ ] At least one real production/category reference is included when available.
- [ ] Gallery/award sources are not treated as proof of UX success.
- [ ] Concept vs production status is recorded.
- [ ] Date checked is recorded for finalists.
- [ ] The source mix matches the decision being made.

## Selection

- [ ] Weak or irrelevant candidates were rejected with reasons.
- [ ] Finalists are selected for fit, not aesthetics alone.
- [ ] 3–6 finalists have distinct roles when scope justifies it.
- [ ] Scores have rationale and are not used as fake precision.

## Transfer

- [ ] Each finalist states transferable principles.
- [ ] Brand-specific/non-transferable elements are identified.
- [ ] Adaptation to project content/assets is described.
- [ ] Mobile implications are considered.
- [ ] Performance implications are considered.
- [ ] Accessibility/usability risks are considered.

## Originality

- [ ] No single site is being cloned.
- [ ] No proprietary assets/copy are planned for reuse without rights.
- [ ] Extracted patterns form one coherent visual grammar.
- [ ] Final rationale ties back to user/business/brand, not trend popularity.

## Handoff

- [ ] Layout grammar cues are clear.
- [ ] Hierarchy/type/color/media cues are clear.
- [ ] Interaction/motion cues are clear when relevant.
- [ ] Conversion/trust cues are clear when relevant.
- [ ] Unknowns and hypotheses are explicit.
