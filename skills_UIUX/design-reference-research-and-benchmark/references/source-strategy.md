# Reference Source Strategy

## Principle

Mỗi nguồn trả lời một loại câu hỏi khác nhau. Chọn nguồn theo **decision cần đưa ra**, không theo độ nổi tiếng của gallery.

## Source taxonomy

| Source type | Strong for | Weak for | Typical examples |
|---|---|---|---|
| Real product / industry site | IA, journey, trust, content hierarchy, conversion, responsive behavior | Không luôn dẫn đầu visual craft | competitor, category leader, adjacent product |
| Curated website gallery / awards | art direction, composition, type, motion, storytelling | Có thể experimental, nặng performance, không chứng minh conversion | Awwwards, MUUUUU, SiteInspire, Godly, CSSDA |
| Landing-page gallery | section sequencing, value proposition, CTA presentation | Có thể thiếu deep product flow | Land-book, Lapa Ninja, One Page Love |
| Case-study platform | brand translation, system presentation, campaign thinking | Nhiều concept không production | Behance |
| Shot platform | component/hero/micro-layout ideas | Context, states, accessibility và responsive thường thiếu | Dribbble |
| Mood platform | imagery, typography mood, editorial/graphic language | Không phải UX evidence | Pinterest, editorial/photography references |

## Query design

Search theo 4 layers khi scope đủ lớn:

1. **Category truth** — website thật trong ngành.
2. **Audience/task** — page/flow phục vụ top task.
3. **Visual expression** — style phù hợp brand.
4. **Cross-industry transfer** — pattern hay từ ngành khác.

Ví dụ cho international school:

- `best international school websites admissions`
- `international school campus website parents`
- `education website editorial design`
- `premium school website awwwards`
- `school website muuuuu`
- `university admissions storytelling website`

Ví dụ cho office building B2B:

- `premium office building leasing website`
- `commercial real estate tenant website`
- `architecture property website awwwards`
- `office building website muuuuu`
- `commercial property availability UX`

## Source ordering by decision

### IA / sitemap / user journey

1. real product/category leaders;
2. accessibility/service exemplars when relevant;
3. competitor benchmark;
4. curated galleries only as secondary inspiration.

### Hero / visual grammar / typography

1. curated website galleries;
2. real premium brands;
3. Behance case studies;
4. Pinterest only for mood/art direction.

### Ecommerce/category/product detail

1. real ecommerce products;
2. category leaders;
3. MUUUUU / curated examples;
4. Dribbble for isolated components only.

### Motion / interaction

1. working production sites;
2. Awwwards/Godly;
3. concept sources as idea-only references.

Always ask: interaction này giúp orientation/task hay chỉ gây novelty?

## Verification rules

Before promoting a reference to finalist:

- open the actual site when possible;
- inspect more than hero/homepage if role depends on deep flow;
- check desktop + mobile behavior when available;
- distinguish current live implementation from old award screenshot;
- identify whether a Behance/Dribbble item is concept or shipped work;
- record date checked because websites change;
- do not claim metrics/results without an explicit credible source.

## Diversity rule

A shortlist should avoid monoculture.

Bad:

- 8 Awwwards sites with cinematic heroes;
- 5 Dribbble shots from the same trend;
- all references from one country/style when audience is broader.

Better:

- category reality + best-in-class visual + cross-industry pattern + art-direction source.

## Freshness

Visual inspiration can age quickly. For trend-sensitive work, prefer recent references while keeping timeless category exemplars when still relevant.

Do not discard older references solely by age if their pattern remains strong.

## Rights / originality

Reference research supports learning and transformation. It does not grant rights to reuse proprietary assets, copywriting, illustrations, photography or distinctive branded compositions.
