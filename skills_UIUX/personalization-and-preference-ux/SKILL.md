# Personalization & Preference UX

## Workflow
1. Separate user-set preferences from inferred personalization.
2. Identify what can be safely remembered.
3. Provide sensible defaults without trapping users.
4. Show when personalization materially changes results or content.
5. Allow reset, edit or disable for meaningful preferences.
6. Clarify cross-device/account sync expectations.
7. Define non-personalized fallback.

## Quality gate
Users can understand and change important preferences; personalization failure has a usable default; sensitive inference is avoided unless justified.
