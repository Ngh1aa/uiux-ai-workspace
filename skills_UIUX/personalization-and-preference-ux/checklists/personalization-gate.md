# Personalization Gate

Each item is pass or fail.

- [ ] Every adaptation is in the inventory and classified explicit, implicit or contextual.
- [ ] Explicit preferences are never silently overridden by inferred behavior.
- [ ] Sensitive categories and their proxies are excluded unless explicit opt-in and confirmed legal basis exist.
- [ ] Every implicitly personalized surface has a plain-language reason and at least one control.
- [ ] Each meaningful preference can be edited, reset or disabled.
- [ ] Reset and clear actions stop data use, verified by a changed result set.
- [ ] Cold-start state is designed and never shows an empty personalized module.
- [ ] Non-personalized fallback works for opt-out, cold start and service outage.
- [ ] Sync scope is shown for account-level preferences; signed-out to signed-in merges ask first.
- [ ] Filter bubble guardrails exist: exploration, decay, source caps and an unpersonalized view.
- [ ] Guardrail metrics are defined beyond click-through.
- [ ] Privacy owner verified current law (GDPR, DSA, CCPA and CPRA or local equivalents) for target markets.
