# Site Search & Findability

## Workflow
1. Model search intents, common vocabulary and high-value destinations.
2. Define search entry point, scope and mobile behavior.
3. Design autocomplete/suggestions without preventing full search.
4. Keep query visible and editable on results.
5. Design result hierarchy, filters and sorting around user criteria.
6. Handle typo, synonym, no-result and refinement paths.
7. Instrument query, zero-result and refinement behavior.

## Quality gate
- Search supports primary retrieval jobs.
- Zero results provide recovery.
- Filter names use user language.
- Suggestion/result interactions are keyboard and focus usable.
