# Search Gate

Mark each item PASS or FAIL with evidence.

- [ ] Top real queries tested; expected top result appears for known-item and navigational queries.
- [ ] Synonym list and best bets exist for high-volume vocabulary mismatches.
- [ ] Search entry is visible where search is a primary path; mobile opens a focused full-screen layer.
- [ ] Active scope is visible and removable.
- [ ] Enter always runs a full search on the typed text.
- [ ] Combobox follows the APG pattern: roles, aria-expanded, aria-controls, aria-activedescendant, arrow keys, Escape.
- [ ] Suggestions never lead to zero results.
- [ ] Query remains visible and editable on results; query, filters and sort are in the URL and survive back.
- [ ] Corrections are shown with "Search instead for" the original; no silent replacement.
- [ ] Facet labels use user language; values show counts; zero-count values cannot produce empty pages.
- [ ] Active filters are removable chips with Clear all.
- [ ] Zero-result page offers correction, filter removal, broader scope, related destinations and a human fallback.
- [ ] Zero-result and refinement metrics are instrumented with a named review cadence and owner.
