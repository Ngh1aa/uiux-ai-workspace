# Portfolio Website Playbook

## Core journey

`First impression → relevant work → understand role/process → proof of quality → fit → contact`

## Case study > gallery

Mỗi featured project nên trả lời:

- Context/client/problem.
- Role/scope.
- Constraints.
- Approach/key decisions.
- Output.
- Result/impact nếu có.

Không cần mọi project dài, nhưng ít nhất featured work phải có narrative.

## Homepage

- Clear positioning.
- Selected work.
- Capabilities/services.
- Credibility/client proof.
- Contact availability.

## Visual craft

Portfolio có thể expressive hơn corporate site, nhưng navigation, readability, mobile và project comparison vẫn phải rõ. Motion không được khiến user “chờ xem showreel” trước khi tìm work.

## Acceptance criteria

- [ ] Positioning rõ.
- [ ] Featured work giải thích contribution/outcome.
- [ ] Contact path visible.
- [ ] Mobile project media/crop tốt.
- [ ] Motion không block browsing.
