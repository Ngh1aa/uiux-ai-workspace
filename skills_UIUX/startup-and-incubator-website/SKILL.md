# Startup & Incubator Website Playbook

## Audience split

- Founders/startups.
- Mentors/experts.
- Investors.
- Corporate/ecosystem partners.
- Media/community.

Homepage phải giúp mỗi nhóm self-select nhanh thay vì dùng một narrative mơ hồ “innovation”.

## Founder journey

`Discover programme → eligibility/fit → benefits/resources → portfolio/outcomes → timeline/process → apply`

## Core content

- Programmes/cohorts.
- Eligibility and application process.
- Mentors/network.
- Portfolio/startups.
- Outcomes/success stories.
- Events/resources.
- Partner/investor opportunities.
- Apply/contact.

## Programme page

Trả lời: dành cho ai, giải quyết stage nào, duration, support, commitments, selection, timeline, outcome và CTA.

## Portfolio

Portfolio startup nên filter theo cohort/sector/stage nếu volume đủ. Detail có founder/company summary, programme relation và outcome/update nếu public.

## Conversion

Application form dài chỉ khi user đã hiểu fit. Trước đó cung cấp eligibility summary/FAQ/info session/contact để giảm low-quality applications.

## Acceptance criteria

- [ ] Audience segmentation rõ.
- [ ] Programme fit/eligibility understandable.
- [ ] Portfolio/outcomes tạo proof.
- [ ] Application timeline/process rõ.
- [ ] Partner/investor path không bị chôn dưới founder content.
