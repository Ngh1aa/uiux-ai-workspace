# Data Tables & Enterprise UX

## Workflow
1. Start from user decisions/actions, not database columns.
2. Prioritize columns and choose density intentionally.
3. Define sort, filter, search and persistence behavior.
4. Design row selection, batch actions and destructive safeguards.
5. Choose pagination, infinite or virtualization based on task and data volume.
6. Design responsive fallback without destroying comparison.
7. Specify accessible names, headers, sort state and keyboard interaction.

## Quality gate
- Headers and table purpose are programmatically clear.
- Sort state is visible and announced.
- Selection/action relationship is unambiguous.
- Mobile alternative preserves core tasks.
